# Non-functional requirements

Reference machine: a mid-range laptop from the last 4 years (e.g. 4+ cores, 16 GB RAM) in a
current desktop browser.

| ID         | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Measure                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **NFR-01** | Privacy: after the initial load (all of the tool's own code and assets fetched, including registering the offline cache and the browser checking it for a new version), the tool makes no network requests of its own; the only exception is the browser's own fetching or update-checking of the tool's own files for the offline cache, which never carries user text; no analytics; the tool never persists user text anywhere (it lives in memory and is discarded when the page closes). Non-content per-device preferences (ENT-Preferences, RULE-14 — toggles, sort, pins, recent-use order) may be stored in local storage and never leave the device (INV-01). The tool's content policy forbids outgoing connections. | Network log during a full session shows zero requests after load; policy header present; local storage holds only the preferences key, never user text. |
| **NFR-02** | Responsiveness: typing or pasting produces updated results within 100 ms of the input settling (settling = the first idle interval after the last change, RULE-08), for input up to the RULE-08 cap; the interface never freezes while converting.                                                                                                                                                                                                                                                                                                    | Interaction-latency traces on 1-line, 1,000-line and cap-sized inputs.                       |
| **NFR-03** | Correctness: tokenization and casing follow RULE-01, RULE-01b, RULE-02, RULE-03, RULE-04, RULE-05, RULE-06 exactly, and pass a fixed adversarial corpus (acronyms such as `HTTPResponse`/`getUserID`, numbers such as `v2Point5`/`utf8`, existing separators, blank lines, and non-cased/Unicode characters) with every row's expected output asserted.                                                                                                                                                                                               | Unit + property tests over the corpus; round-trip stability is explicitly _not_ required.    |
| **NFR-04** | Accessibility: WCAG 2.2 AA; every action operable by keyboard; the copy confirmation, a copy failure, and any notice are announced to assistive technology; result rows have accessible names.                                                                                                                                                                                                                                                                                                                                                        | Automated audit + manual screen-reader pass.                                                 |
| **NFR-05** | Startup: interactive within 1.5 s on a 10 Mbit/s, 40 ms round-trip connection with a cold cache; within 0.5 s when cached. A size budget for the initial download is set in the architecture.                                                                                                                                                                                                                                                                                                                                                         | Lab measurement with network throttling.                                                     |
| **NFR-06** | Browser support: latest two versions of the major desktop browser engines (Chromium-, Gecko- and WebKit-based); usable down to 320 px wide without horizontal scrolling (phone layouts of the host included; WCAG reflow); embedded and standalone.                                                                                                                                                                                                                                                                                                   | Test matrix.                                                                                 |
| **NFR-07** | Embedding safety: the tool can only be embedded by configured host origins and accepts settings messages only from them (RULE-10); it never sends user text to the host (INV-01).                                                                                                                                                                                                                                                                                                                                                                     | Header check + message-origin tests.                                                         |
| **NFR-08** | Touch targets: every interactive element (result rows, controls) is at least 24×24 CSS pixels, with adequate spacing, per WCAG 2.2 target size.                                                                                                                                                                                                                                                                                                                                                                                                       | Layout audit at 320 px and desktop widths.                                                   |
