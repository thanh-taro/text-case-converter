# Personas

- **PER-01** — _Working developer._ Writes code, config and docs daily and constantly needs a
  string in a different casing convention: a database column to an API field, an env var to a
  config key, a label from a ticket, Slack message or spec into a variable name. Often has a
  **list** of names to convert at once. Reads the source text in a browser tab, not yet in the
  editor. Distrusts sites that upload data; notices when a converter mangles acronyms like
  `HTTPResponse` or numbers like `v2`.
- **PER-02** — _Portal maintainer._ Owns the developer-tools portal that embeds this tool. Wants
  it to look native in the portal (theme, sizing), need no backend, and stay out of the way.
