# Roadmap

### M-1 — Core value

Enter text (type/paste/clear), see all eleven cases live (RULE-01), correct tokenization of
acronyms and numbers (RULE-02), per-line batch conversion (RULE-03), click any result to copy
(RULE-07), host integration (theme/sizing/embedding), privacy statement, and offline use.
Features: F-001 … F-007.

### M-2 — Smarter & more

Detect and highlight the input's apparent case; optional keep-acronyms-uppercase handling
(RULE-06); a few more case kinds (e.g. Train-Case, COBOL-CASE) if demand appears; keyboard
navigation across the result grid.

### M-3 — Preferences & polish

Remembered preferences (which result rows are shown, ordering) — settings only, never content;
larger-input hardening beyond the RULE-08 cap.

### M-4 — Candidates

Detect-and-suggest the most likely target case; share a conversion recipe without the text;
transliteration/slug mode.
