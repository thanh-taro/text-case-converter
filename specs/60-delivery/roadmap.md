# Roadmap

### M-1 — Core value

Enter text (type/paste/clear), see all eleven M-1 cases live (RULE-01), correct tokenization of
acronyms and numbers (RULE-02), per-line batch conversion (RULE-03), click any result to copy
(RULE-07), host integration (theme/sizing/embedding), privacy statement, and offline use.
Features: F-001 … F-007.

### M-2 — Options & ordering

Strip-symbols toggle (F-008, RULE-11); remove-accents toggle (F-009, RULE-12); sort and pin the
result grid with a last-used badge (F-010, RULE-13), all remembered on the device (RULE-14).
Features: F-008 … F-010.

### M-3 — Smarter & polish

First: use the portal's language — en-US and vi-VN from the host's address or messages, else the
browser's (F-011, RULE-15; shipped in v1.2.0). Then: mark the rows that match the input (F-012,
RULE-17); keep acronyms in capitals (F-013, RULE-16); move through results with the keyboard
(F-014); Train-Case and COBOL-CASE (F-015, RULE-01); shipped in v1.3.0.
Features: F-011 … F-015.

### M-4 — Candidates

Detect-and-suggest the most likely target case; share a conversion recipe without the text;
transliteration/slug mode (kebab-case with the default switches already gives ASCII slugs; revisit for non-Latin scripts); larger-input hardening beyond the RULE-08 cap (moved from M-3).
